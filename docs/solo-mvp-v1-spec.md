# 单人主线 V1 规格

范围固定为“选本、工具、档案”，不恢复匹配、组局或多人选本。

1. 内容治理：剧本保存风险代码、内容状态、来源、版本和核验时间；缺失资料显示未知。
2. 本次条件：用户可设置人数、最长时长和难度硬条件。硬条件先过滤，再按长期口味排序。
3. 可解释对比：最多选择 3 本，比较适合点、风险、未知信息和规则依据；比较与列表共用评分规则。
4. 单次游玩：笔记和记录可关联个人游玩批次；反馈区分剧本内容、角色、DM 和同桌，只用用户确认的剧本内容反馈影响推荐。
5. 证据提示：AI 只能读取当前用户选中的笔记，输出来源 ID、核查步骤和不确定点；来源不存在或不属于本人时拒绝。

兼容约束：已有接口字段保持不变，新字段和参数均为可选；SQLite 迁移采用新增列/表；个人资源始终校验所有权。验证使用 Node 集成测试、小程序状态测试和微信开发者工具 mock 运行时检查。
